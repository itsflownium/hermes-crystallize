## Updating and activating

Check that the installed checkout is clean, preserve its revision, then use a
fast-forward update. Use the host's public plugin activation control while idle.
If a restart is needed, use the normal live-work guard; interruption requires
explicit authorization. Do not reset local edits, force a restart over active
work, modify existing production jobs or copy provider credentials.

An approved native wrapper never self-updates. A runtime review warning requires
Undo followed by a new complete source review and explicit attachment. Model and
reasoning fields are preserved. Test jobs are finite, local and separately
identified; their cleanup and actual scheduled outcomes are recorded with the
live report. The plugin itself does not pull, install or restart anything.
